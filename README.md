# Crate Rescue: Detroit

A browser game about blind inventory in construction: extra building materials hide in six
real Detroit construction yards, a drone scans them, a built-in AI dispatcher suggests where
each crate should go, and robot trucks deliver them before they're thrown away.

Everything the game needs is inside `index.html`. `og-image.png` is only the preview picture
shown when the link is shared.

To publish with GitHub Pages: upload `index.html` and `og-image.png` to the top level of a
public repository, then in Settings > Pages choose "Deploy from a branch", branch `main`,
folder `/ (root)`.
